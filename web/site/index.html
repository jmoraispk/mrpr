Open the 10,000-line MR. All of it.

Agents don't write small diffs. Once an MR touches a few hundred files, GitLab stops showing every change. Mr. PR's diff viewer is built for that size: every file listed, loaded as you scroll, with generated and lock files folded out of the way.

Questions

Is Mr. PR an AI code reviewer?+

No. Mr. PR is for the human reviewer. It works alongside whatever AI review bots your team already runs, and folds their comments away until you want them.

GitLab already has a merge request homepage. Why this?+

It's a good list of where each MR stands. Mr. PR adds what a list can't: ranking by who's blocked, diffs since your last review, noise filtering, actions from the inbox, and one view across several GitLab instances.
