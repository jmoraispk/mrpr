Questions

Is Mr. PR an AI code reviewer?+

No. Mr. PR is an inbox for the human reviewer. It works alongside any AI review bots your team already runs.

GitLab and GitHub already have merge request pages. Why this?+

GitLab and GitHub simply list your merge requests. Mr. PR helps you organize them and get them closed.

When is GitHub support coming?+

GitHub is next on the roadmap. Join the waitlist and you'll be the first to know when it's ready.

Does it work with self-managed GitLab?+

Yes. Sign in with OAuth or a personal access token. Because Mr. PR talks to GitLab straight from your browser, it works with any instance your browser can reach, even one behind your company VPN.

Do you store my source code?+

No. Mr. PR runs in your browser and talks to GitLab directly. Your access token stays on your device, and your code and comments never pass through our servers. Private by design.
