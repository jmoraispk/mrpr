Using it

  1. Open Mr. PR and go to Settings.
  2. Paste the code into the license field.
  3. The reminder stops. Nothing else changes, because nothing else was ever gated.

The code lives in your browser, so paste it again on another browser or on your phone. There is no device limit and no account to sign into.

What this does not do

It does not phone home, check in, or expire. Mr. PR never asks anyone whether your code is valid, because there is nobody to ask: the app is static and has no server behind it. The code is a receipt, not a lock, and this runs on the honor system.
